# Portfolio Website Instructions

## Project
Build a professional single-page portfolio website for Ralph Jerome T. Yu.

## Technology
- Astro
- TypeScript
- HTML and CSS
- Do not add React or another framework unless specifically requested.
- Use semantic, accessible HTML.

## Design Direction
- Clean technical portfolio
- Responsive desktop and mobile layouts
- Support light and dark modes
- Use CSS variables for colors and spacing
- Keep the interface professional and suitable for recruiters and clients

## Main Sections
- Home
- About
- Projects
- Contact
- Footer

## Featured Projects
1. Woodberry Resort and Events Booking and Management System
2. Lost and Found Website for Local Schools

## Development Rules
- Keep components small and reusable.
- Avoid unnecessary dependencies.
- Do not use placeholder content when real project information is available.
- Preserve existing functionality when editing files.
- Run `npm run build` after major changes.
- Explain changed files and verification results after completing a task.
